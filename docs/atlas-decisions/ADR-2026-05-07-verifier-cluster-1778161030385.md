### Why the original close shipped an empty diff

`verifier/src/lib/spec-parser.ts` extracts `filesRequired` only from paths that match (a) backtick inline code with a recognised file extension, (b) markdown table cells, or (c) bullet lists prefixed `src|supabase|agent|verifier|adela`.
