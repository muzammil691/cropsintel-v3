Resolved by `SCAN_EXCLUSIONS` in `6d7a626` and `de58d26`.
2. **e2e-smoke crash on missing runner deps (Bug — fixed).** Resolved by `38c97e5`.

No new code change is in scope for this investigation (per acceptance criterion 2).
